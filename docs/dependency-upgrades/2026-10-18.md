## Qualification boundary

The [retained validation receipt](2026-10-18/validation.json) records package
changes, source hashes, browser measurements, and these local outcomes:

- Frozen frontend installation, typecheck, 848 tests (3 skipped), and production
  build pass. The downstream extension frontend passes 873 tests (3 skipped)
  and its composed build.
- The CI-pinned pnpm 10.34.5 accepts the frozen lockfile in an isolated directory
  with lifecycle scripts disabled. It does not replace the active dev server's
  pnpm 11-managed modules.
- All 20 Chromium/WebKit dialog/motion cases pass with zero entry opacity
  reversals, retained nodes through exits/reopening, and no settled displacement.
  Four transcript configurations pass with zero overlap, replacement, duplicate
  commands, status/finish height shift, or page errors.
- Rust formatting, 802 Nextest tests (8 skipped), core WASM compilation, and the
  macOS native host's all-targets compilation pass. Public boundary checks pass
  13/13. Locked metadata has no declared dependency minimum above Rust 1.94.
- **Strict Clippy fails**, so the compiler migration is not qualified for CI.
  Rust 1.99.1 reports `chunks_exact_to_as_chunks` at protocol lines 134 and 533
  and the capture simulator's line 512.
  A diagnostic probe allowing only that lint also finds a needless borrow at
  provider engine line 475 and `result_large_err` for the provider's 192-byte
  recoverable failure context. That probe is not an acceptance gate. No lint
  suppressions or source fixes are committed or applied.

The repository rule against editing untouched files after compilation breaks
requires a decision on these additional source changes. The proposed minimal
migration is fixed-size `as_chunks` iteration, removing the unnecessary borrow,
and boxing the recoverable error context with its constructors/callers updated.
The question about allowing those compiler fixes remains pending. Current
toolchain pins are a candidate, not a claim that all required gates pass.

Local Rust checks use the existing ignored
Cargo path override for the sibling agent checkout. A downstream composition
must consume a committed foundation revision, synchronize its own Rust
toolchain/lockfile and worker cache identities, and rerun exact-source CI and
platform packaging before release. Its current release pin is not changed by
this review. No active desktop application is restarted, no signing identity
is used, and no paid-provider tests are run.
